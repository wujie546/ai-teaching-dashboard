# 專案規則與設定 (陳文舟老師 - 115.07.23 Vibe Coding 教學儀表板)

## 📌 基本資訊
- **專案名稱**：用 AI 打造專屬教學儀表板
- **使用者稱呼**：總編
- **技術棧**：Vanilla HTML / Vanilla CSS / Modern JavaScript (ES6)

## 🎯 專案目標
- 為教學設計一個直覺、美觀、具有科技感與現代感的儀表板。
- 介面需要支持：
  - 教學進度追蹤
  - 學生互動數據分析
  - 課堂評分與反饋圖表
  - AI 助教小工具 (語音、快速筆記)
- **設計風格**：
  - 採用深色科技風（Dark Mode/Glassmorphism）與精心調配的 HSL 漸層。
  - 使用 Google Fonts (Outfit / Inter)。
  - 豐富的微互動、Hover 動效與過渡動畫。

## ⚠️ 開發規範
- **稱呼偏好**：請一律稱呼使用者為「總編」。
- **程式碼結構**：保持 HTML 語意化、CSS 模組化且具備豐富的變數定義、JavaScript 模組化或結構清晰。
- **生圖工具**：優先使用 Google 內建的 `generate_image`。
